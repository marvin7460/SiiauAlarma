# Seguridad / Security

**Español.** Si encuentras una vulnerabilidad en ¿Hay Cupo?, repórtala en privado desde la pestaña
**Security → Report a vulnerability** de este repositorio, no en un issue público. Incluye los
pasos para reproducirla. Respondo en cuanto pueda; por favor no la publiques hasta que esté
corregida. No hagas pruebas que afecten a otros usuarios ni a SIIAU (nada de inundar el sitio de
peticiones). Cómo está protegido el proyecto: [docs/security.md](docs/security.md).

**English.** If you find a vulnerability in ¿Hay Cupo?, report it privately through this
repository's **Security → Report a vulnerability** tab, not in a public issue, with steps to
reproduce it. Please do not disclose it until it is fixed, and do not test in ways that affect
other users or SIIAU (no flooding the site with requests). How the project is protected:
[docs/security.md](docs/security.md) (in Spanish).
